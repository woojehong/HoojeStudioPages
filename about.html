제작을 맡기는 시간이 번거롭지 않도록

후제공방은 월드 오브 워크래프트 한국 아즈샤라 서버에서 한 명의 플레이어가 운영하는 비공식 제작 보조 서비스입니다.

왜 사이트를 만들었나요?

게임 안에서는 어떤 제작자가 어떤 품목을 만들 수 있는지, 필요한 재료가 무엇인지 매번 설명하기 어렵습니다. 후제공방은 품목과 재료를 한곳에 정리하고 주문이 접수됐는지 이용자가 직접 확인할 수 있도록 만들었습니다.

사이트와 애드온은 주문자와 제작자 모두의 반복 확인을 줄이는 도구입니다. 자동으로 장비를 제작하거나 게임 서버의 결과를 바꾸지는 않습니다.

세 가지 운영 원칙

수수료는 자율입니다

최소 주문 단위만 보내도 제작하며 정해진 수수료를 요구하지 않습니다.

등록된 품목은 최고 품질을 기준으로 합니다

주문자가 금성 필수 재료를 모두 준비했다는 조건으로 안내합니다.

가능 여부와 지연을 숨기지 않습니다

현재 상태와 주문 진행 단계를 사이트에서 확인할 수 있도록 운영합니다.

비공식 개인 서비스입니다

후제공방은 Blizzard Entertainment, Wowhead 또는 외부 배너에 표시되는 사이트와 제휴·승인 관계가 아닙니다. 게임 관련 명칭과 자산의 권리는 각 권리자에게 있으며, 후제공방이 제작한 UI·문구·삽화는 별도 창작물입니다.

정보를 관리하는 방법

품목과 재료는 게임 내 한국어 명칭과 주문 제작 화면을 우선 확인합니다. Wowhead를 비롯한 외부 데이터는 누락을 찾고 아이템·아이콘 식별자를 대조하는 참고 자료로 사용하며, 외부 정보 하나만으로 결과를 확정하지 않습니다.

제보가 들어오면 웹사이트의 품목 데이터와 HoojeStudio 애드온의 제작자·재료 데이터를 함께 확인합니다. 변경 이유를 확인하지 못했거나 게임 클라이언트와 충돌하는 정보는 서둘러 반영하지 않습니다.

문의와 수정 요청

재료 오류, 잘못된 제작자 배정, 사이트 또는 애드온 문제는 메인 화면 우측 하단의 제보 기능으로 접수합니다. 불필요한 개인정보나 계정 정보는 입력하지 마세요.
