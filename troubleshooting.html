주문이 멈추거나 반송될 때 확인할 순서

같은 실패 문구라도 재료 누락, 제작자 선택, 재제작 상태, 게임 서버 응답처럼 원인이 다를 수 있습니다. 후제공방에서 실제 주문을 처리하며 사용하는 확인 순서를 정리했습니다.

작성·검수 후제공방 운영자최종 갱신 2026.09.04한밤 시즌 2 기준

보내기 전에 먼저 확인합니다

  1. 사이트에 표시된 제작자와 게임 주문 창의 수신자가 같은지 확인합니다.
  2. 필수 재료의 종류와 수량이 모두 채워졌는지 확인합니다.
  3. 품질이 있는 필수 재료는 모두 금성인지 확인합니다.
  4. 서신·장식·힘 주입 재료가 의도한 선택과 맞는지 확인합니다.
  5. 최초 제작인지, 기존 장비를 다시 만드는 재제작인지 구분합니다.

후제공방이 반송 사유를 남겼다면 그 문구를 먼저 확인하세요. 재료 누락이나 제작자 오지정처럼 주문자가 바로 고칠 수 있는 문제와, 게임 UI 또는 서버 응답처럼 즉시 해결하기 어려운 문제를 구분하기 위한 기록입니다.

제작 버튼을 누른 뒤 지연이 생기는 경우

일부 재제작 주문에서는 버튼을 누른 직후 화면이 잠시 멈춘 것처럼 보이고, 이어서 주문 제작 실패 문구가 나타나거나 주문 완료 버튼이 반응하지 않는 증상이 관찰됐습니다. 특정 품목이나 특정 재료만의 문제라고 확정할 근거는 아직 부족합니다.

같은 주문을 연속해서 반복 실행하지 마세요첫 시도가 실패했다면 주문 목록과 재료 반환 여부를 먼저 확인하고, 주문 창을 닫았다가 다시 연 뒤 상태를 확인합니다. 재료와 장비가 어디에 있는지 확인되지 않은 상태에서 반복하면 원인 파악이 더 어려워집니다.

재제작이라면 추가로 봅니다

재제작은 현재 넣은 재료만으로 판단할 수 없습니다. 기존 장비가 만들어질 때 사용된 재료 품질과 시즌, 적용된 서신·장식, 현재 주문 창이 요구하는 조건이 함께 영향을 줄 수 있습니다. 다른 제작자가 만든 장비는 후제공방에서 최초 제작 기록을 확인할 수 없으므로 한 번의 재제작으로 결과를 보장하기 어려울 수 있습니다.

시즌 전환 장비는 게임 패치와 핫픽스에 따라 가능한 조합이 달라질 수 있습니다. 사이트 설명보다 게임 주문 창의 현재 요구 조건을 우선하고, 실패가 반복되면 품목명·현재 아이템 레벨·재제작 여부·표시된 오류 문구를 함께 제보해주세요.

애드온 영향을 구분하는 방법

오류가 애드온 경고창에서 발생한 것인지, Blizzard 기본 주문 창에서 발생한 것인지 먼저 구분합니다. HoojeStudio는 재료와 주문 조건을 확인하는 보조 도구이며 게임 서버의 제작 판정을 바꾸지 않습니다.

  1. 게임과 HoojeStudio가 현재 인터페이스 버전에 맞는지 확인합니다.
  2. 오류 메시지에 표시된 애드온 이름과 파일·줄 번호를 기록합니다.
  3. 문제가 반복되면 HoojeStudio만 켠 상태와 다른 UI 애드온을 함께 켠 상태를 비교합니다.
  4. 레이드·던전·필드처럼 주문 기능이 필요하지 않은 장소에서는 HoojeStudio 기능이 제한될 수 있습니다.

애드온을 끈 상태에서도 Blizzard 주문 창에서 동일하게 실패한다면 애드온 자체보다는 주문 데이터나 게임 서버 처리 문제일 가능성이 높습니다. 반대로 Lua 오류에 HoojeStudio 파일과 줄 번호가 표시되면 해당 오류 전문을 제보해 수정 범위를 확인합니다.
