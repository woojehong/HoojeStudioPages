제작 정보가 주문 실수로 이어지지 않도록

후제공방은 품목 이름만 모아놓은 목록이 아닙니다. 실제 주문 창과 제작 캐릭터의 학습 여부를 기준으로 품목·재료·제작자 정보를 확인하고, 제보가 들어오면 웹과 애드온을 함께 점검합니다.

확인 자료의 우선순위

  1. 게임 클라이언트의 한국어 주문 제작 화면에서 품목명, 요구 재료, 품질과 선택 칸을 확인합니다.
  2. 제작 캐릭터의 전문 기술 목록에서 실제 학습 여부와 제작 가능 여부를 확인합니다.
  3. 실제 접수된 주문에서 사이트 안내와 게임 화면이 일치하는지 다시 확인합니다.
  4. Wowhead 등 외부 데이터는 아이템·아이콘 식별자와 누락 후보를 찾는 교차 확인 자료로 사용합니다.

외부 데이터와 게임 화면이 다르면 현재 한국 클라이언트의 실제 주문 화면을 우선합니다. 패치 직후에는 번역과 데이터 반영 시점이 서로 다를 수 있으므로 한 자료만 보고 성급히 확정하지 않습니다.

품목마다 확인하는 항목

품목명한국 클라이언트에 표시되는 이름과 검색에 사용되는 표기를 확인합니다.
제작자해당 도안을 실제로 배운 후제공방 캐릭터에 배정됐는지 확인합니다.
필수 재료종류, 수량, 품질 단계와 빈 칸 여부를 확인합니다.
선택 재료서신, 장식, 힘 주입처럼 주문자가 선택하는 칸을 필수 재료와 구분합니다.
제작 범위일반 장비와 PvP 장비의 제작 가능 여부 및 최고 품질 기준을 확인합니다.

오류 제보를 처리하는 순서

제보 내용을 원문 그대로 확인합니다

품목명, 잘못 표시된 제작자나 재료, 실제 게임 화면을 구분해 기록합니다.

게임 안에서 다시 검증합니다

제작 캐릭터의 도안과 주문 창을 열어 제보가 현재 패치에도 재현되는지 확인합니다.

웹과 애드온의 동일 항목을 함께 찾습니다

한쪽만 수정하면 이용자마다 다른 안내를 보게 되므로 양쪽 데이터를 대조합니다.

수정 후 검색과 주문 흐름을 점검합니다

카테고리, 검색 결과, 재료 복사, 제작자 표시와 애드온 경고가 함께 맞는지 확인합니다.

제보가 서로 충돌하거나 재현되지 않으면 바로 단정하지 않고 보류합니다. 확인되지 않은 정보를 빠르게 반영하는 것보다, 실제 주문에서 다시 확인할 수 있도록 기록을 남기는 것을 우선합니다.

웹과 애드온을 함께 관리하는 이유

웹사이트는 품목을 찾고 재료를 정리하는 역할을 하며, HoojeStudio 애드온은 게임 주문 창에서 같은 정보를 확인하도록 돕습니다. 두 데이터가 다르면 웹에서는 올바른 제작자를 봤더라도 게임 안에서 다른 경고를 받을 수 있습니다.

그래서 제작자 배정이나 필수 재료가 바뀌면 웹 데이터, 애드온 데이터, 직접 다운로드 ZIP, 게임 설치 테스트본을 한 묶음으로 확인합니다. 애드온 코드 변경은 Lua 구문 검사와 정적 검사를 거치고, 공개 배포 전에는 압축 파일 안에 폴더와 TOC·Lua 파일이 올바른 위치에 있는지도 확인합니다.

시즌과 패치가 바뀔 때

시즌 제작 수는 새 시즌 기준으로 분리하되 누적 제작 기록은 유지합니다. 신규 품목과 PvP 도안, 재료 종류, 인터페이스 번호를 점검하고 기존 페이지에 남은 이전 시즌 문구도 함께 찾아 수정합니다.

핫픽스로 조건이 바뀔 가능성이 있는 내용은 영구적인 규칙처럼 표현하지 않습니다. 페이지마다 최종 검수일과 적용 시즌을 표시하고, 이용자는 품목 페이지와 게임 주문 창의 최신 상태를 최종 기준으로 확인할 수 있습니다.

작성 원칙 이 기준은 후제공방을 실제로 운영하며 발생한 제작자 오배정, 재료 누락, 패치 호환성 제보를 처리하기 위해 사용하는 절차입니다. 자동 수집 결과만으로 품목 정보를 확정하지 않습니다.
